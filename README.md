# Название проекта

Интернет-магазин мебели.

## Описание
Проект, представляющий собой многостраничный веб-сайт. Цель - создать удобный для пользователя визуальный интерфейс, красиво выглядящий на любых устройствах. Задачи - создание удобной навигации, создание форм, кнопок, использование псевдоклассов для отдельных ссылок или кнопок

## Сроки выполнения
На работу мне понадобилось в общем 10 недель. 7 недель на техническую часть и 3 недели на доработку.

## Технологии
Основной стек технологий:
*   **HTML5** — семантическая структура страницы.
*   **CSS3** — стилизация, Flexbox/Grid, адаптивность.
*   **Git & GitHub** — контроль и место хранения версий проекта.

## Запуск проекта
Чтобы запустить проект локально, выполните следующие шаги:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Dmitrij544/my-site.git
2. Перейдите в папку проекта.
3. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
   *Рекомендуется использовать расширение **Live Server** в VS Code для корректной работы ссылок.*
